# EOG 地图编辑器

启动：

```text
npm run editor:map
```

打开 `http://127.0.0.1:8766/`，按区域依次审核。

1. 选择区域并点击“定位本区”。
2. 地块模式调整中心和点击框；地形、港口、补给源只读。
3. 连线模式直接点击线段，或依次点击两个地块新增连接。
4. 为每项选择决定和状态，填写必要备注。
5. 修改完成后点击“保存全部修改”；编辑器会按地块和连接端点自动归入涉及区域并原子提交，无需逐区保存或逐项确认。

升级编辑器代码后需要停止旧进程并重新运行本命令。开发脚本使用Node watch模式，后续服务器代码变化会自动重载。

跨区连接需要两个相关区域分别确认。未确认和有争议的内容只保存在 `data/source/map_audit.json`，不会写入正式地图数据。

生成区域核验图：

```text
npm run audit:map:render
```

输出位于 `tmp/map-audit/`：

- `*-formal.png`：当前正式数据。
- `*-proposed.png`：当前草稿。
- `*-confirmed.png`：已确认内容。
- `*-checklist.md`：地块和邻接清单。

全部五区完成后执行：

```text
npm run audit:map:confirmed
```
